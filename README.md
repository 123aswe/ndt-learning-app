# NDT 学习刷题平台（劳人无损检测学习 App）

面向无损检测（NDT）行业的**一站式学习备考平台**，覆盖考生端、管理后台、官网与微信小程序四端，内置超声（UT）、射线（RT）、磁粉（MT）、渗透（PT）四个方向共 **1740 题**一级题库，并集成 **AI 智能助手**（题目解析 / 视频概括 / 计算题解答过程生成）。

> 本仓库为开源学习交流版：**只包含源码与内置题库，不包含任何密钥、数据库与用户数据**，部署后即可开箱体验。

---

## ✨ 功能亮点

- **AI 智能助手**：集成智谱 GLM 大模型，题目 AI 解析、视频 AI 概括、计算题解答过程自动生成，SSE 流式输出
- **AI 公式排版**：AI 输出的 LaTeX 公式（行内 / 块级）由自研 Markdown + KaTeX 管线渲染为真正的数学公式
- **多模态理解**：视频概括先做宫格图（contact sheet）拼接再送入视觉模型，突破单请求图片数量限制
- **完整学习闭环**：题库（系列 → 题库 → 章节）→ 练习 → 考试 → 错题本 → 学习报告 → 成就系统
- **六种题型**：单选 / 判断 / 多选 / 计算 / 计算选择 / 简答，练习与考试全部服务端判分
- **四端一体**：考生端 SPA、可视化后台、官网、微信小程序（web-view 套壳）共用一套后端
- **全局音乐引擎**：跨页面后台播放 + Web Audio 频谱动效 + 可拖动悬浮球 + 系统媒体卡片（MediaSession）
- **主题商店**：后台上传皮肤 → 前端 CSS 变量动态换肤，深色模式全适配

## 🚀 快速开始

### 环境要求

- Node.js 18+（前端）
- Python 3.10+（后端，FastAPI）

### 一键启动（Windows）

1. 双击根目录 **`启动App.bat`**：自动检查 Node、安装依赖、启动前后端并打开浏览器
2. 首次启动后端时会**自动导入内置题库**（1740 题，UT/RT/MT/PT），并自动创建默认管理员

### 手动启动

```bash
# 前端（开发服务器 http://localhost:8443，/api 自动代理到 8000）
npm install
npm run dev

# 后端（服务 http://127.0.0.1:8000）
cd server
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

### 访问入口

| 入口 | 地址 |
| --- | --- |
| 官网 | `http://127.0.0.1:8000/` |
| 考生端 App | `http://127.0.0.1:8000/app/` |
| 管理后台 | `http://127.0.0.1:8000/admin/` |
| 接口文档 | `http://127.0.0.1:8000/docs` |

默认管理员账号：**admin / admin123**（上线前请务必修改密码）

### 公网访问（可选）

双击 **`启动公网访问.bat`** 即可通过 Cloudflare 快速隧道把本机服务发布为公网地址（地址每次重启会变化，见控制台输出）。

## ⚙️ 配置说明

后端配置文件为 `server/config.json`（**不在仓库中**），首次运行前从 `server/config.example.json` 复制：

```bash
cd server
copy config.example.json config.json
```

需要按需填入：

- `ai.api_key`：智谱开放平台 API Key（**AI 解析 / 视频概括 / 解答生成**依赖此项，不填则 AI 功能降级为不可用，其余功能正常）
- `sms.*`：腾讯云短信密钥（注册短信验证码，不填则走图形验证码）

## 🔒 安全说明

本仓库刻意**不包含**以下内容（`.gitignore` 已强制忽略）：

- `server/config.json`（智谱 API Key、短信密钥）
- `server/data/`（SQLite 数据库、上传的资料/音乐/图片、数据库备份）
- SSL 证书私钥（`*.key` / `*.crt`）、公网隧道地址

如需二次分发，请自行保管好你的密钥与数据文件。
