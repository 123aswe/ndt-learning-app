资料库

在这里上传标准规范 / 教材 / 辅导资料 / 视频课程，保存后考生端 App「教材 / 视频」页会动态出现。 文件保存在服务器 data/uploads/ 目录，标题与分类信息保存在数据库。
上传时可指定封面图（jpg / png / webp，≤8MB）；不指定的话，视频在考生端会自动取首帧作为封面。 列表里的播放量 / 收藏数 / 评论数来自考生端真实行为，点「评论」可查看并删除违规评论。
列表前面的序号按当前筛选结果实时编号；点排序列的 ↑ / ↓ 可以调整资料的展示顺序 （资料、视频、系列都支持，新上传的默认排在最前面），考生端顺序实时同步。

资料系列

系列是大类下面的一层分组（例如「UT 培训视频合集」「2024 版标准合辑」）。 考生端「教材 / 视频」页会先把系列显示成卡片，点进去才是该系列里的全部资料。
新建系列后，在上传/编辑资料时选择所属系列即可把资料放进去； 没有归入任何系列的资料会集中在考生端「其他资料 / 其他视频」里展示。

系列与资料列表前面的序号跟着当前筛选结果实时编号；点排序列的 ↑ / ↓ 即可上移 / 下移，考生端「教材 / 视频」页的顺序会立刻跟着变（考生端还可在页面上切换顺序 / 倒序）。

音乐

在这里上传歌曲：音频文件 + 封面图 + 歌手名 + 歌词，保存后考生端 App「音乐」页即可在线播放 （真实音频播放，支持播放 / 暂停、上一曲 / 下一曲、拖动进度条，到点自动下一曲）。
歌词支持纯文本（一行一句）或 LRC 时间轴格式：每行写成 [00:12.34] 这一句歌词，考生端会按时间逐行高亮滚动；写不出时间轴也没关系， 没有时间轴的歌词会整段滚动展示。
音频支持 mp3 / m4a / wav / flac / ogg 等浏览器可直接播放的格式（单个文件 ≤200MB）； 封面支持 jpg / png / webp（≤8MB），不上传封面时考生端自动使用内置山水插画。

主题商店

在这里上传主题（皮肤）：一张背景图 + 主色 / 辅色 / 字色，考生在 App「我的 → 主题商店」里自选一个应用。
应用后同时作用于登录 / 注册页与登录后的主界面：背景图按 cover 铺满（裁剪、不拉伸）， 配色覆盖按钮 / 强调色 / 文字与卡片底色 —— 只改颜色与背景、不动任何尺寸，界面不会变形。
字色决定文字明暗基调：背景偏浅选「深色字」，背景偏深选「浅色字」；选反了会出现文字看不清。
预览图只用于后台列表与考生端缩略图，不上传时考生端用主色 / 辅色渐变兜底；背景图支持 jpg / png / webp（≤15MB）， 预览图同格式（≤8MB）。删除主题不影响其它主题；考生本机若正用着被删的主题，会自动恢复默认外观。

版本发布

在这里发布新版本，此刻正在使用 App 的考生会立刻收到更新提示（走实时通道推送，不用等轮询）。 普通版本弹可关闭的顶部提示条，「强制更新」弹不可关闭的更新弹层。
网页版考生点「立即更新」= 刷新页面即拿新版（构建产物带内容哈希）； 如果还提供打包版 App，请填下面的安装包 / 下载地址，弹层里会多一个「下载新版本」按钮。

只有比考生当前版本大才会提示。发布前请先改前端 src/data/appVersion.ts 的 APP_VERSION 并重新构建部署，否则考生刷新后拿到的还是旧版本。
考生正在答题 / 考试时一律不打扰，交卷回到主界面后再提示。
