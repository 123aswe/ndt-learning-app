# UI 设计规范（NDT-劳人 · 苹果式浅色极简）

> 用户指定的视觉标准，优先级最高。任何页面/组件必须符合，禁止回退到旧深色玻璃风格。

## 整体风格
专业、安静、高效的学习工具（苹果式克制美学），不是娱乐 App。无 AI 感：不堆砌渐变、发光、玻璃拟态、装饰波形、粒子等「AI 生成感」元素。

## 1. 背景与表面
- 页面背景：纯白 `#FFFFFF` / 浅米白 `#FAF9F6` / 浅灰蓝 `#F3F4F6` 三选一，全 App 统一用 `#F3F4F6`
- 卡片表面：纯白 `#FFFFFF`，需要区隔的辅助面用 `#FAF9F6`
- 避免强烈对比与花哨装饰

## 2. 文字
- 主文字：深炭黑 `#1B1E23`
- 次要文字：中灰 `#5F6670`
- 弱化/说明：`#9AA1A9`
- 功能标签用低饱和辅助色，不用高亮色

## 3. 辅助色（1–2 种低饱和）
- 主色（按钮/进度条/重点信息/选中态）：低饱和蓝绿 `#5F8D8C`
- 正确状态：低饱和绿 `#6FA37C`
- 错误状态：低饱和红 `#C17B7B`（功能状态色，非品牌色）
- 所有颜色低饱和、低对比，禁止霓虹色

## 4. 布局
- 留白充足：页面左右 20px，卡片间距 ≥12px，卡片内边距 16–20px
- 信息密度适中，不堆满屏幕；卡片之间间距大

## 5. 卡片与阴影
- 柔和圆角：卡片 16–20px，按钮 12–14px，胶囊 999px
- 阴影非常轻：`0 1px 2px rgba(27,30,35,0.04), 0 4px 16px rgba(27,30,35,0.05)`
- 禁止厚重阴影、强烈立体感、发光

## 6. 字体层级
- 标题：粗无衬线（Inter 600/700 + PingFang SC），`-0.01em` 字距
- 正文：简洁无衬线 400/500
- 数字/进度：清晰醒目，等宽数字建议（font-variant-numeric: tabular-nums）

## 7. 图标
- 极简线性图标：stroke 统一 1.6–1.8，圆头端点，造型克制
- 来源：`src/components/icons.tsx`，禁止 emoji 图标、复杂插画

## 8. 图表与统计
- 只保留关键数据：极简柱状图、环形进度、数字卡片
- 去掉多余网格线、装饰曲线、渐变填充、发光

## 9. 交互与动效
- 状态：默认/选中/正确/错误/禁用，用低饱和色区分，不只靠颜色
- 动效克制：淡入淡出、轻微位移即可，时长 ≤0.4s；禁止持续背景动画、弹跳、震荡

## 页面级要求
| 页面 | 关键要求 |
| ---- | ---- |
| 首页 | 顶部问候、中部进度卡片/今日目标/正确率、下方题库分类入口；卡片式、留白大 |
| 题库分类 | 顶部搜索框；分类卡片/标签列出题数、进度、完成状态 |
| 题目详情/答题 | 题干突出；选项卡片：未答浅灰边框、正确低饱和绿、错误低饱和红；底部提交/下一题 |
| 答题卡 | 简洁网格按钮，已答/未答/标记用低饱和色区分（本项目暂无独立答题卡页，答题页进度条承担） |
| 错题本 | 列表卡片：题目来源、错误次数、正确率、知识点标签 |
| 学习统计 | 刷题量、正确率、连续天数、章节掌握：极简柱状/环形/数字卡片 |
| 个人中心 | 头像区简洁，菜单列表清晰，卡片/列表呈现 |
