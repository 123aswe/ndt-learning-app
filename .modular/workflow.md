# 工作流（两阶段 + 文档驱动）

```text
用户需求（一次性给完整需求）
  ↓
───────── 阶段一：界面设计 ─────────
  ↓
1. 需求理解 + 项目理解（读 architecture.md / frontend.md / backend.md）
2. 模块定位 + 依赖 + 影响分析
3. 设计全部界面（含基础点击 / 导航 / Mock 数据）
4. 实时同步 frontend.md
5. 阶段一验证（可运行、可点击、无报错）
  ↓
──── 等待用户确认 UI 后进入阶段二 ────
  ↓
───────── 阶段二：逻辑代码 ─────────
  ↓
6. 编写逻辑代码（功能独立实现）
7. 实时同步 backend.md
8. 阶段二验证（build / 运行全过）
9. 文档收尾
10. Git checkpoint + 变更说明
```

## 本项目适用分支
- 本次任务 = **UI Development（纯前端视觉重构）**：结构/逻辑不动，只改视觉。
  流程：读 frontend.md 定位 → 只改对应模块样式与组件 → 验证可运行 → 更新 frontend.md。
- 新增功能走完整两阶段；修复 Bug / 重构按 SKILL.md 对应分支。
